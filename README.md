# my-first-site · 窗内夜雨

1em0 的个人主页。整个页面是一扇雨夜的窗：你站在屋里，隔着起雾的玻璃看窗外的城市灯火。

纯 HTML + CSS + 原生 JavaScript 编写，没有框架、没有构建步骤、没有任何外部资源（字体、图片、音频全部内置或实时合成），国内访问也不受影响。

## 页面里有什么

**首屏：窗**
- 两层画布：后面是失焦的城市灯光（琥珀色路灯、冷色窗光）和湿漉漉的街面倒影，前面是玻璃上的雨丝、涟漪和水珠
- **在玻璃上擦一擦**：鼠标划过或手指滑动，会擦掉玻璃上的雾气，露出清晰的城市；几秒后雾会慢慢重新蒙上
- 水珠会长大、合并，变重后顺着玻璃滑下，留下水痕
- 风会时不时吹过，让雨丝、水珠一起倾斜；偶尔一阵急雨
- 夜里极少数时候会有一道很柔和的远处闪电（低对比度，不会刺眼）
- 名字 `1em0` 在开场时字距从散开慢慢收拢，同时有一只"手"把名字前的雾抹开
- 左下角的时间短句会根据访客本地时间变化（黄昏 / 深夜 / 快天亮了……）

**往下滚：一场雨从下到停**
- 关于我、我的兴趣、联系方式三个区块，雨势随着滚动时大时小，雨声和灯光也跟着变化，到页脚渐渐停下
- 兴趣卡片：悬停或点按时从指尖处泛起一圈水纹，玻璃反光扫过
- 联系方式是四盏路灯，悬停或聚焦时灯泡点亮，地面倒影跟着变亮
- 页脚是黎明：最后几滴雨落下，窗台水洼里倒映着名字，「雨停了。天快亮了。」

**控件**
- **撑伞 / 收伞**：在「夜」和「阴雨白昼」两套主题之间切换。默认跟随系统深浅色设置，手动选择会被记住
- **听雨**：用 Web Audio 实时合成的雨声，默认关闭，只有点击后才会出声

**照顾到的细节**
- 手机、平板、电脑都能正常显示，任何宽度下都没有横向滚动
- 系统开启「减少动态效果」时，雨会定格成一幅静止的画面，所有大幅动画关闭，页面依然完整
- 性能：画面离开屏幕或切到后台时暂停动画；会自动检测帧率，设备吃力时降低分辨率和粒子数量
- 可以只用键盘操作，所有按钮都有读屏标签

## 文件结构

```
.
├── index.html   # 页面结构和全部文字内容（入口文件）
├── style.css    # 样式：两套主题配色、布局、动画、响应式
├── rain.js      # 首屏的雨、雾、水珠、城市灯光（Canvas 绘制）
├── audio.js     # 用 Web Audio 合成的雨声
├── script.js    # 主题切换、滚动叙事、交互、时间短句等
└── README.md
```

## 修改内容

页面里所有需要你替换的个人内容都是普通的 HTML 文字，集中在 `index.html` 中。
在 `index.html` 里搜索 **`占位`** 就能找到每一处，前面都有 `<!-- 占位：替换这里 -->` 注释：

- 一句话简介
- 关于我（两段文字 + 一句短句）
- 四个兴趣的标题和描述
- 四个联系方式的链接（`href`）和显示文字
- 页脚文字

标着「设计文案，非个人信息」的地方（如「往下看」「在玻璃上擦一擦」）是页面本身的文案，可以不改。

## 本地预览

直接用浏览器打开 `index.html` 即可，不需要安装任何东西。

## 发布到 GitHub Pages

1. 打开仓库的 **Settings → Pages**
2. 在 **Build and deployment** 中，Source 选择 **Deploy from a branch**
3. 选择 `main` 分支和 `/ (root)` 目录，保存
4. 稍等片刻，页面会发布到 `https://<用户名>.github.io/my-first-site/`
